# Candy Parkour Rush

A simple mobile-friendly parkour runner game built with HTML, CSS, and JavaScript.

## Features

- Start screen with Start and Settings buttons
- English keyboard-style controls: A, D, W
- Speed bar inspired by Roblox-style movement feedback
- Speed grows by step progression
- Level progression through staged goals
- "تريد ميل" upgrade system with five paths and colors
- Candy/chocolate themed world
- Cup rewards for each stage
- Touch buttons for mobile play

## Run locally

Open `index.html` in a browser.

Or serve it with a local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — app layout
- `style.css` — visual design and mobile layout
- `script.js` — game logic and controls

## Notes

The game is intentionally lightweight and optimized for browser play on mobile devices.
